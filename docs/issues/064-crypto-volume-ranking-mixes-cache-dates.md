# 064 — Crypto 成交额排名混合缓存日期

日期：2026-09-07。状态：新 beta 入口已防御；原 PMARP 行为保持原样。

## 发现
云端 Quant 的 `binance_pmarp_scanner.get_top_n_symbols()` 取各缓存最后一行成交额，未验证共同日期；缓存数量不足100时退回滚动24h成交额。直接复用会让“昨日成交额前50”口径不成立。

## 本次处理
新 beta 扫描固定 UTC 昨日，读取该日唯一 quote_volume；缺失才请求2根K线，仍缺失则阻断排名。前50之外只获取排名需要的成交额，不计算beta；31根完整日线仅用于前50及BTC。上市不足31天不替补、不用0/1填充。

## 验证
真实528/528成交额齐全、50个入选、46个beta有效；独立OLS对拍46个，最大差1.33e-15。日期缺失/陈旧/重复测试全部通过。
