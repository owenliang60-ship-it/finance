# S2 MA20 预热和缺数不能伪造上穿

- 发现：2026-09-23，日报 S2 拆分 SPY/QQQ/SOXX/Extended 时。
- 原因：`close > rolling(20)` 将均线未形成的 NaN 比较成 False，再记为 0；首次有效均线上方比例可能从这个假 0 上穿。另一个路径删除缺数日期，会把不相邻交易日拼成相邻上穿，并压缩 60 日冷却的计数。
- 修复：MA20 未形成时保持 NaN，保留交易日位置；四组独立计算，沿用 MA20、30% 上穿、60 个交易日位置冷却。ETF 使用最近完整周频成分快照，SOXX 对应已有 SOX 存储键，保留双类别股票；Extended 使用正式 base resolver，不含 overlay。
- 数据约束：按当前成员固定回看 260 根行情（不是历史 PIT 成分回测）；ETF 快照超过 14 个自然日则 N/A；每个交易日有效 MA20 覆盖至少 95%，展示有效/总成员数，缺数不回退 Broad。Extended 的 PMARP 不适用。
- 验证：`tests/test_morning_s2_universes.py` 覆盖独立冷却、预热、缺数、快照时效、SOXX 小篮子、成员身份、三种展示和只读计算。
