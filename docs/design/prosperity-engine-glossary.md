# 美股景气引擎 — 术语表

> **日期**: 2026-09-26 ｜ 配套 `prosperity-engine-requirements.md`、`prosperity-engine-research.md`

## 数据与时点

| 术语 | 含义 |
|---|---|
| PIT（point-in-time） | 某个历史时点当时真正能看到的数据版本，不含之后的重述和补录 |
| 前视偏差（look-ahead bias） | 回溯时用到了当时还不存在的信息 |
| 近似 PIT（`approximate`） | 用当前（可能重述过的）数据，只按提交日过滤。本地 2026-08-22 之前的历史都属于这一类；`fmp_earnings` 没有版本，补跑里的 street EPS 始终属于这一类 |
| `pit_basis` | 景气引擎每行的点时等级：`live`（当周实时计算、输入值已存档）/ `strict`（补跑读 vintage）/ `approximate`；按来源分别判定，整行取最弱 |
| vintage | 同一数据点的某一个版本；`fundamental_vintage` 按内容变化 append-only 记录 |
| `announce_date` | 业绩公告日（8-K / 新闻稿），来自 `fmp_earnings` |
| `filing_date` / `accepted_date` | 10-Q / 10-K 提交日 / EDGAR 接收时间戳。景气引擎以 `accepted_date` 为可得时间，缺失时退回 `filing_date` |
| 重述（restatement） | 公司或数据商事后改写已发布的数字 |
| 52/53 周财年、14 周季度 | 部分公司按周计财年，每 5–6 年多出一周，通常落在 Q4，使该季比正常季长约 7.7% |
| 16/12 周季度结构 | COST、KR 等公司 Q1 为 16 周、其余为 12 周，环比会机械地 −25% / +33% |
| 天数折算 | 流量科目乘以 91 / 实际季度天数，消除季度长短差异 |
| 混合时点截面 | 周榜里有的公司已报本季、有的还停在上季 |
| `quarter_bucket` / `data_age_days` | 最新季度映射到的日历季 / 距季末的天数，用来标注混合时点 |
| 幸存者偏差 | 只用今天还存在的公司回溯，漏掉退市和被并购的公司 |

## 因子与口径

| 术语 | 含义 |
|---|---|
| 同比（YoY） | 本季相对去年同季的增长 |
| 环比（QoQ） | 本季相对上一季的增长 |
| 同比加速度 | 本季同比 − 上季同比（pp）。对数口径下等于"本季环比 − 去年同季环比" |
| 季调环比 | 扣除季节成分后的环比，常用"本季环比 − 往年同季环比" |
| 两年叠加（two-year stack） | 本年同比 + 去年同比，用来抵消低基数 |
| 低基数效应 | 去年基数异常低时，今年的增速或加速度被算术放大 |
| SUE | 标准化意外盈利。景气引擎口径（Novy-Marx）：(本季 EPS − 去年同季 EPS) / σ，σ 取本季之前最近 8 次同比变化的标准差（不含本季、不减均值，至少 6 个观测）。文献中另有减历史均值的版本，本项目不用 |
| ΔSUE | 本季 SUE − 上季 SUE（两季各用各自窗口的 σ），即景气引擎的 EPS 加速因子 |
| SURGE | 营收版的 SUE |
| PEAD | 财报后漂移：业绩超预期后股价继续同向漂移，大盘股中约 2006 年后基本消失 |
| earnings surprise | (实际 EPS − 一致预期) / 股价，或用 SUE 式标准化 |
| 一致预期（consensus） | 分析师预测的平均值；`fmp_estimates` 是周频快照 |
| 预期修正（revision） | 同一组固定财季的一致预期在两个时点之间的变化 |
| 修正广度（breadth） | (上调家数 − 下调家数) / 总家数；FMP 不提供，只有 yfinance 有 |
| NTM EPS | 未来 12 个月 EPS。本地默认用下 4 个未公告季度（公告日晚于 as_of，含季末已过、尚未公告的那一季）的一致预期求和（Rule A）；远季分析师 <3 人时退回 FY1/FY2 时间加权（Rule B）；每股先换美元再换 ADR 单位。详见北极星"NTM 契约" |
| TTM EPS | 过去 12 个月 EPS。景气引擎用最近 4 个已公告季度的 street 实际值求和 |
| street / adjusted EPS | 剔除一次性项目后、与多数分析师预测口径一致的 EPS |
| GAAP EPS | 按会计准则报告的 EPS（利润表口径）；与 street 口径不能混比 |
| E/P（盈利收益率） | EPS / 股价；盈利跨零时连续，排序用它代替 PE |
| NTM / TTM PE 比值 | 等于 1 / (1 + 预期 EPS 增速)，与预期增速是同一个信息 |
| PEG | PE / 预期增速；美国大盘股缺少学术证据，只展示 |
| GP/A | 毛利 / 总资产；学术上比毛利率水平更有效 |
| CbOP | 现金基础经营盈利能力；比 FCF 率变化证据更强 |

## 打分与流程

| 术语 | 含义 |
|---|---|
| winsorize（缩尾） | 把超出 μ±3σ（或分位边界）的值压到边界 |
| z 值 | (值 − 均值) / 标准差，截面标准化 |
| mask | 参与 z 值计算的股票集合；只包含过了门槛且数据合格的股票 |
| 覆盖率重新摊权 | 缺失的因子不填中性值，其权重按比例分给有数据的因子 |
| 行业中性化 | 在板块内标准化，去掉行业水平差异；本项目只可能在 11 个 sector 层做 |
| 因子族 | 高度共线的一组因子（如加速度与季调环比），合计权重设上限 |
| 趋势加减分 | 按近 8 季毛利率斜率在全池的百分位加减 −10 到 +10 分 |
| STRICT / FULL / BELOW | 评级三档：分数 ≥65 / ≥50 / 其余，另有净利率守卫和次新三关 |
| 方案（scheme） | 一套因子集合 + 权重 + 变换 + 门槛的配置，带版本号和 `scheme_hash` |
| 周榜（weekly / live） | 每周六数据刷新后生成的榜单 |
| 财报季最终榜（`quarter_final`） | 季末 60 天后首个覆盖率 ≥95% 的周六冻结，80 天硬上限；是冻结当周周榜的不可变拷贝，另存财季标签与 `frozen_at`；前瞻收益从 `frozen_at` 后起算 |
| 参数包（`params_version`） | 季末冻结时估计、之后周榜沿用的标准化参数：缩尾边界、μ、σ、斜率分档，排名方案另含参考分布；还没有冻结榜时用当周截面自举（`params_bootstrap`） |
| 体检报告（tearsheet） | 每个方案的固定格式报告：分层前瞻收益、IC、换手、行业集中度、与价格动量重叠、失败案例 |
| IC / ICIR | 分数与前瞻收益的秩相关 / IC 均值除以其标准差 |
| Fama-MacBeth 式推断 | 先逐期算统计量，再对期值做 t 检验 |
| BH-FDR | 多重比较时控制错误发现率的校正 |
| 短史因子 / 长史因子 | 只能从 2026-07 起积累的 forward 类因子 / 能回溯到 2021 的财报类因子 |
| fail-closed | 数据缺失或校验失败时明确判为不可用，不当作通过或空池放行 |
