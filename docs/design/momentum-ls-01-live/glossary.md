# 动量多空1号实盘术语

日期：2026-10-19。用于本子系统设计，具体交易所字段以验收时的官方协议为准。

|术语|在本项目里的含义|
|---|---|
|子账户隔离|试验资产与其他账户分开；不代表逐币逐仓|
|全仓保证金|子账户内合约共用可用保证金，币种间损失会互相影响|
|杠杆设置|决定初始保证金要求的交易所配置；不代替策略目标仓位|
|名义敞口|持仓币数乘价格；本策略调仓目标gross为净值100%或150%|
|账户权益|钱包余额加未实现盈亏；与可用保证金、名义敞口不同|
|维持保证金|维持当前仓位所需的最低保证金，随合约档位与名义规模改变|
|合约成交价|CONTRACT_PRICE；本策略原生止损的触发价格源|
|标记价格|MARK_PRICE；用于交易所未实现盈亏与强平计算，可能与成交价不同|
|价差触发保护|priceProtect；开启时价格触及阈值仍须满足价差条件；本项目关闭|
|单向持仓|同一合约只有一个净持仓；整个账户仍可在不同合约同时多空|
|意图|系统持久化的拟执行动作。意图已记录不表示交易所已接受|
|普通订单|开仓、减仓等订单，有独立订单ID与成交回报|
|Algo保护单|交易所条件服务保存的止损；触发后还需追踪实际普通订单和成交|
|全仓位止损|closePosition=true，触发时关闭该合约对应方向仓位；不是全账户平仓|
|只减仓|reduceOnly=true；用于普通退出委托，禁止意外开出反向风险；不能与全仓位条件单参数混传|
|未知提交|请求可能成功但响应丢失。先查询/对账，不把超时当失败重发|
|持仓周期|某合约从零仓位到再次归零的episode；止损版本、成本与冷却绑定该周期|
|对账|独立比较本地意图、成交账、交易所订单/持仓/权益；差异不能靠覆盖本地值消失|
|目标快照|绑定规则版本、信号截止时间、周锚点、账户状态和输入哈希的不可变调仓目标|
|前向观察|规则冻结之后真实发生的结果；不能与已反复看过的回测样本混称盲测|

事实依据：[币安交易接口](https://developers.binance.com/en/docs/catalog/core-trading-derivatives-trading-usd-s-m-futures/api/rest-api/trade)、[强平机制](https://www.binance.com/en/support/faq/detail/360033525271)、[保证金公式](https://www.binance.com/en/support/faq/detail/b3c689c1f50a44cabb3a84e663b81d93)。意图、持仓周期、目标快照为本项目设计术语。
