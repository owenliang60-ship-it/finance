> **日期**: 2026-09-25
> **来源**: 原站 research.foresightfn.com 解密后的输出 `data/external/foresight_fm/prosperity.json`（47 期，2015-03 → 2026-09-02 live）、页面 JS `prosperity_js.js`、TODO 页 `todo.txt`

> **用途**: 景气引擎 Phase 2/3 的输入；复刻验收（R1/R3）以此为准

## 1. 股票池与防前视（原站口径，我们不照搬股票池）

- 每季末取过去 30 个交易日**平均**成交额前 50（Polygon 全市场数据，含退市股）
- 用财报发布日判断数据是否可用（earnings），找不到时退回 filingDate
- 至少 6 个已披露季度；覆盖率 < 0.5 的不排名；上市不满 6 季的新股走单独的年报粗估路径（不参与主排名）

## 2. 6 个因子（字段名 = JSON 键）

| 字段 | 定义 | 单位 |
|---|---|---|
| `revenue_yoy_accel` | 本季营收同比 − 上季营收同比 | pp |
| `revenue_yoy_pct` | 单季营收同比 | % |
| `gm_yoy_pp` | 毛利率 − 4 季前毛利率 | pp |
| `gm_pct` | 毛利率 | % |
| `inv_days_yoy_pp` | 存货天数同比变化；存货天数 = 存货 ÷ (营业成本/90)；打分时方向取反 | 天 |
| `fcf_margin_yoy_pp` | FCF/营收 的同比变化 | pp |

同比按位置取 [i−4]，缺季时会出错，原站只打了日志。
补丁：存货天数 < 1 → 存货因子置 NaN；|FCF 率| 或 |Δ| > 200 → FCF 因子置 NaN；FCF/capex 恰好为 0 且有营收 → 视为缺失。

辅助字段：
- `gm_slope`：近 8 季毛利率 OLS 斜率
- `net_margin_yoy_pp`：净利率同比
- `capex_int_yoy_pp`：capex 强度同比，capex 强度 = capex/营收
- `fsm_state` / `fsm_mult` / `fsm_agg_mult` / `fsm_capex_mult`：库存周期状态及各级乘数
- `within100`：组内分
- `cov`：覆盖情况
- `dq`：数据质量标记
- `ipoDate`、`is_new_listing`：次新判定
- `bs[方案]` = {s 分数, b 基础分, t 评级, w 降级原因, wi 组内分}
- `*_series`：8 季序列，只用于画图

## 3. 打分步骤

1. **z 值**：每个因子在全池（跨行业）先把 μ±3σ 以外的值压到边界，重算 μ、σ（ddof=0）后算 z，再截到 ±3。存货因子取反向。NaN 记为 0。
2. **库存周期乘数**只乘在存货因子的 z 上，状态由营收方向 × 存货天数方向决定：
   - 被动去库（营收↑、天数↓）：×0.414
   - 主动补库（↑↑）：×1。囤货最猛的前 25%（按存货天数增幅）×1.517；再按 capex 强度Δ微调：增 ×0.949，减 ×1.058
   - 被动补库（↓↑）：×2.037
   - 主动去库（↓↓）：×1
   - 无存货：×1
3. **合成**：comp = Σ(z·m·w) ÷ Σ(有数据因子的 w)。缺失因子不填中性值，权重重新摊给其余因子。
4. **基础分**：base = (clip(comp, −2, 2) + 2) / 4 × 100。
5. **趋势加减分**：按 `gm_slope` 在全池的百分位分档：≥90% +10、70–90% +6、55–70% +2、30–55% 0、10–30% −5、<10% −10。加在 base 上，**不再截断**（所以分数可以 > 100）。
6. **评级**：
   - 分数 ≥65 为 STRICT，≥50 为 FULL，其余为 BELOW
   - 非次新股：净利率同比 < 0 → 降为 BELOW，原因标"净利率↓"；净利率数据缺失不罚
   - 次新股（上市 < 730 天）：必须同时满足营收增速 ≥75%、毛利率 ≥40%、分数 ≥70，否则降为 BELOW，原因标"次新未达标"
   - 排序：先按评级，再按分数
7. **组内分**：同业务组至少 5 只时，组内重算 z 再打分；只作参考，不参与排序。

## 4. 原站自报的回测（B 方案，STRICT 等权持有 3 季，2015–2025，共 42 个窗口）

- STRICT 组合平均 3 季收益 +31.6%，QQQ +14.8%；超额 QQQ +16.8%，超额池均值 +19.1%；11 年里 7 年正超额
- 逐年超额（年份：%）：15:−14，16:+24，17:+12，18:−6，19:+37，20:+16，21:−15，22:−8，23:+44，24:+62，25:+55
- 单因子前 20% 组合表现接近随机（48–52 百分位）；合成后的 STRICT 在 57 百分位
- regime 观察：STRICT 里有银行的季度，之后 4 季 QQQ 约 −8%；零银行的季度 +25.9%（只有两轮周期）

## 5. 我们实测发现的问题（写进体检报告和改良方向）

- **基础分饱和**：STRICT 里 15%（26/179）的基础分顶到 100，榜首靠趋势加减分排先后
- **净利率闸门断崖**：因净利率降级的 362 次里，81 次（22%）净利率同比只降了不到 1pp
- **尺度耦合**：|营收二阶导| 与 |营收同比| 的秩相关，美股 0.36、A股 0.44；百分点相减在高增长票上被放大
- **二阶导的本质**：二阶导 ≈ 本季环比 − 去年同季环比，相当于季节调整后的环比；但一半取决于去年的基数，所以会把低基数恢复读成加速（原站自己实锤：AMC 2021 年 105 分 → −64%/−83%，UPST −90%）
- **capex 强度的分母陷阱**：营收暴涨会稀释 capex 强度，被误判成"减 capex"
- **其他**：参数（库存乘数、趋势分档）来自 A股 优化器拟合；页面默认方案（v38）不是回测验证过的方案（B）；超额集中在 2023–2025；独立样本约 14 个；没有价格动量和行业中性这两个对照组
- **"绝对景气"名不副实**：分数是当期池内的相对位置，不是绝对景气
