## 固定执行流程（5 步）

1. **解析标的与周期**：
   - 未指定周期时，默认 `timeframe = "1D"`；支持任意单周期（`4h` / `1D` / `1W`）或多周期。
   - 若只提供裸代码（如 `SOXX`、`NVDA`、`BTC`），先调用 `tradingview:mcp-tv-search-symbols` 确认准确 `EXCHANGE:TICKER`（美股/ETF 优先 `NASDAQ` / `NYSE` / `AMEX`，加密现货优先 `BINANCE:xxxUSDT`）。禁止猜测交易所前缀。
2. **并行拉取四路数据**：
   - 同一轮并行调用：
     - `tradingview:mcp-tv-get-ohlcv`（`count: 10`，取最新收盘价、涨跌幅、OHLCV 与时间戳）
     - 上表 3 个指标的 `tradingview:mcp-tv-run-pine-indicator`（`return_bars: 10`，传上表锁定 `inputs`）。
   - 跑 1D 时，建议同一轮再加一次 `#1` 的 1W 调用，供一屏结论的「1W 大级别趋势背景」行使用。不加跑时，该行写「1W 背景：未拉取」。
3. **完整性门控（Fail-Closed）**：
   - 任一 MCP 调用返回失败、未授权或超时，直接报错并停止输出综合结论，禁止用估计值填补。
   - 解析字段时以 `metainfo.plots` 中 `title` 匹配 `plot_id`，不硬编码易漂移编号。
   - 核对两张面板 `table` 的隐藏输出字段是否齐全（#1 含 `MCP_共振状态`..`MCP_D超跌阈值`；#3 含 `MCP_盘面定性码`..`MCP_S历史分位`）；缺失则显式标明降级项。
4. **按「趋势 / 极端 / 交易量」三板块拆解并交叉判读**（见下节）。
5. **按固定输出模板交付**（面板 `table` 全部字段必须逐项列出，不得省略或折叠）。

## 三板块归属、面板全量字段映射与判读规则

### 统一高亮规则（`🚨 + 加粗`，全文只在此定义）

「当根」= 最新已收盘 K 线（1D 周期即当日 K 线），对照前一根已收盘 K 线判断。只有当根新触发下表事件时，才在一屏结论与所属板块用 **`**🚨 ...**`** 高亮。近 10 根内的历史旧事件只用普通文字记录，不加 `🚨`。

| 板块 | 当根新触发事件 |
|---|---|
| 趋势 | 趋势翻多、翻空、共振切换或触及/跌破 Supertrend 止损翻向：`ST翻多`、`ST翻空`、`奶牛翻多`、`奶牛翻空`、`双多共振触发`、`双空共振触发` 任一非 0 |
| 极端（Extremity Z+S） | `位置 Z` 新上穿或下穿 `±1.5σ` 警戒轨 / `±2.0σ` 极值轨（含 `下穿 -1.5σ`、`下穿 -2.0σ`、`防抖上穿 -2.0σ (极值止跌)`、`防抖上穿 -1.5σ (超跌反转)`、`防抖下穿 +2.0σ (过热退潮)`、`防抖下穿 +1.5σ (强势衰减)` 触发，以及原始 `位置 Z` 跨过动态轨道） |
| 极端（原版偏离 D） | `MCP_原版偏离D` 新上穿或下穿 `MCP_D过热阈值`（90%）/ `MCP_D超跌阈值`（10%） |

---

### 板块一：趋势（Trend）— 来自 `#1 Supertrend + 奶牛趋势通道融合版` 前半层
必须完整输出右上角面板前 5 行 + 通道中枢 + 近 10 根翻向事件：
- `共振状态`：`MCP_共振状态`（`1`=双多共振、`-1`=双空共振、`0`=信号分歧）
- `Supertrend (14, 2)`：`Supertrend 多头止损` 非 null = 做多；`Supertrend 空头止损` 非 null = 做空
- `ST 收盘逆转价`：做多时显示 `跌破 <ST多头止损>`，做空时显示 `站上 <ST空头止损>`
- `奶牛通道 (EMA30±1ATR)`：`MCP_奶牛方向`（`1`=做多、`-1`=做空、`0`=待确认）
- `奶牛临界 (上/下沿)`：`奶牛上沿 (+ATR)` / `奶牛下沿 (-ATR)`（并附 `奶牛中枢 EMA`）
- 近 10 根翻向事件：`ST翻多`、`ST翻空`、`奶牛翻多`、`奶牛翻空`、`双多共振触发`、`双空共振触发`

**判读要点**：
- 回答「现在是什么趋势、是否共振、右侧翻转/止损的关键价位在哪里」。
- 高亮：按「统一高亮规则」趋势行。

---

### 板块二：极端（Extremity）— 双路极端指标交叉印证（`#3 Extremity Z+S` + `#1 原版偏离 D`）

1. **双轴极端度 Z + S（`#3 Extremity v6.0`）** — 必须完整输出右下角面板全部 5 行 + 动态轨道 + 近期拐点：
   - `盘面定性`：`MCP_盘面定性码` 字典映射：
     - `-3`：恐慌急杀 · 慎接飞刀（Z ≤ -2σ 且 S ≤ -2σ 速度极值）
     - `-2`：减速超跌 · 观察企稳（Z ≤ -2σ 但跌速已收敛）
     - `-1`：超跌警戒 · 弱势下探（-2σ < Z ≤ -1.5σ）
     - `0`：常态区间
     - `1`：急杀回踩 · 假极端（Z 仍在中位但 5 日急跌）
     - `2`：慢牛钝化 · 禁逆势（Z ≥ +1.5σ 但未喷发）
     - `3`：喷发过热 · 止盈警戒（Z ≥ +2σ 或 +1.5σ 配速度喷发）
   - `位置 Z`：`位置 Z` + `MCP_位置Z_σ`（格式化为 `Z (-2.00σ)`，并列动态轨道 `滚动中枢 / ±1.5σ / ±2σ`）
   - `Z 2年分位`：`MCP_Z历史分位`（`%`）
   - `5日速度 S`：`MCP_速度S` + `MCP_速度占极值%`（格式化为 `S (-57%极值)`）
   - `S 2年分位`：`MCP_S历史分位`（`%`）
   - 近 10 根事件：`恐慌急杀 · 慎接飞刀`、`急杀回踩 · 假极端`、`极值止跌 (-2σ 防抖)`、`过热退潮 (+2σ 防抖)`
2. **原版偏离 D（`#1` 右上角面板后 3 行）** — 必须完整输出全部 3 行：
   - `原版偏离 D (EMA84)`：`MCP_原版偏离D`
   - `D 历史分位 (2Y)`：`MCP_D历史分位`（≥90% 标 `过热`，≤10% 标 `超跌`）
   - `2Y 极值 D (90%/10%)`：`MCP_D过热阈值` / `MCP_D超跌阈值`

**判读要点与防误判硬规则**：
- 回答「偏离到了什么历史极端位置、速度是在加速还是减速、双路极端信号是否共振」。
- 高亮：按「统一高亮规则」两条极端行。
- 处于 `-3 恐慌急杀` 时，禁止输出“可抄底”结论；需等跌速收敛（进 `-2`）或触发 `-2σ` 防抖 `止跌` 再转观察企稳。
- 处于 `2 慢牛钝化` 时，禁止仅凭高位就建议逆势做空。
- 处于 `1 急杀回踩 · 假极端` 时，明确提示并非大级别底部极端。

---

### 板块三：交易量（Volume）— 来自 `#2 Vol + RVOL 放量融合版`（120 / 标准差 2σ）
必须完整输出：
- `当日成交量`（`成交量`）、`Vol MA (20)`（`Vol MA`）、`放量阈值线 (+2σ)`（`放量阈值线`）
- `RVOL 倍数`、`量能 Z-Score (σ)`
- 当日及近 10 根异动事件：`放量上涨异动`、`放量下跌异动`、连续放量集群与缩量演变。

**判读要点**：回答「当前是放量突破/派发/恐慌宣泄，还是缩量阴跌/反抽」，用于验证趋势翻向或极端位置的筹码换手真实性。

## 固定输出模板（聊天正文）

每次调用严格按以下结构输出，先给结论再展开三板块面板全量读数：

1. **顶部元信息（1 行）**：
   `标的 (EXCHANGE:TICKER) · 周期 · 最新收盘价 (涨跌幅) · 最新 K 线日期（盘中需注明未收盘）· 数据源：TradingView MCP`
2. **一屏综合结论（4 条短句 + 1W 背景行 + 可选基准率行，先结论后数据；🚨 按「统一高亮规则」）**：
   - **趋势定性**：当前方向、是否共振、右侧翻向价位。
   - **极端定性**：Extremity Z+S + 原版偏离 D 双路是否一致处于极值，以及速度是加速还是减速。
   - **量能印证**：放量/缩量对上述趋势与极端信号的强化或削弱作用。
   - **关键观察位与边界**：列出具体价位/状态切换条件；注明翻向与止跌以收盘确认为准，仅供参考。
   - **1W 大级别趋势背景**（默认 1 行）：跑 1D 时写 1W 的共振状态与 ST 方向，并说明 1D 信号顺不顺 1W；未拉 1W 时写「1W 背景：未拉取」。本身就是 1W 周期时省略。
   - **条件历史基准率**（可选）：只有已有历史回测或 `tradingview:mcp-tv-run-pine-backtest` 统计时才写，格式「同类状态 n=<样本量>，后 5 日胜率 X% / 后 20 日胜率 Y%」。没有统计时不写，不凭印象估。
3. **板块一：趋势（ST + 奶牛通道面板）** — 完整列出面板前 5 项 + 中枢 + 近 10 根翻向。
4. **板块二：极端（Extremity Z+S 面板 + 原版偏离 D 面板）** — 完整列出 Extremity 面板 5 项与动态轨道、原版偏离 D 面板 3 项及近 10 根拐点。
5. **板块三：交易量（Vol + RVOL，回看 120 / 2σ）** — 完整列出量能数值、阈值线、RVOL、Z-Score 及近 10 根放量异动。
6. **轻量接力块（可选）**：Boss 要接 `/options` 或 `/deep-analysis`，或明确要求时，在末尾附下列 YAML。只填 MCP 实际返回的值；缺失填 `null` 并列入 `degraded`。

   ```yaml
   ta_handoff:
     symbol: NASDAQ:NVDA       # EXCHANGE:TICKER
     timeframe: 1D
     bar_date: 2026-11-26      # 最新已收盘 K 线日期
     close: 0.00
     st_direction: long        # long = ST 多头止损非 null；short = ST 空头止损非 null
     st_stop: 0.00             # 对应方向的 Supertrend 止损价
     cow_upper: 0.00           # 奶牛上沿 (+ATR)
     cow_lower: 0.00           # 奶牛下沿 (-ATR)
     regime_code: 0            # MCP_盘面定性码（-3..3）
     z_sigma: 0.00             # MCP_位置Z_σ
     trend_1w: null            # 1W 共振状态；未拉取为 null
     degraded: []              # 缺失或降级字段名
   ```
