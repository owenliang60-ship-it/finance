# 美股主题篮子拥挤度指标（Theme Crowding V2.2）

> 关联单号：Linear `OWE-28`（交易指标项目 `P-OWE-6`）
> 数据权限：对 `data/market.db` **严格只读**（`?mode=ro` / `?immutable=1`），零写入生产库，不参与景气 `code_version` 哈希。

## 1. 定位与设计演进

本模块在 A 股行业拥挤度（500 交易日滚动百分位、`0–10` 分制）基础上，针对美股科技与周期龙头特征完成三轮升级与独立验证：

1. **美股本土化升级（V2）**：把单点 243 日动量改为 `MA200` 年线偏离度；给 20 日超额波动率加 `60` 日回撤门控（防止熊市暴跌打出满分拥挤）；成交量全部改为 **5 日均值**（成分股真实成交额占本库美股普通股比 + 成分股总换手率）；估值维度改用聚合 **市销率倒数 `TTM SP = sum(TTM_Rev) / sum(MCap)`**（规避半导体周期顶点利润率暴涨导致的市盈率“假便宜”陷阱）。
2. **双脑辩论定稿（V2.2，Neon × Fable）**：
   - 5 个子指标在进入共同有效区后统一做因果 **`EMA3`（`span=3`）后置平滑**：单日跳变降逾九成、零滞后，且满足严格线性可加（三维度均分相加 100% 等于总分 `EMA3`）。
   - **非对称回看窗口**：量价与波动维持 **500 交易日（约 2 年）**，慢变量估值 `TTM SP` 采用 **500–1000 交易日（约 2–4 年）有界扩展窗口**，消除两年单边牛市的估值分位漂移。
   - **双阈值迟滞状态灯**：偏热黄灯 `>= 8.0` 亮、`< 7.5` 灭；拥挤红灯 `>= 9.0` 亮、`< 8.5` 灭。
   - **低分区（`< 5.0`）三态语义**：区分 `放量回调换手/分歧（非缩量）`、`温和低分区` 与 `缩量冷清低位`。
3. **Codex（`gpt-6.2-astra` `xhigh`）全量对拍加固**：修复 `historical_market_cap` 瞬时单位脏点（如 `BRK-B` 连续 8 天跌千倍）、补齐 `QQQ`/`SOX` 2021 年起季报 PIT 持仓、锁死 `T-1` 换仓收益归属与市值加权、接入 `fundamental_vintage` 版本隔离与负 `TTM` 显式撤销、去重市场分母别名并对齐前端状态着色。

## 2. 定稿公式（三大等权维度 × 5 项子指标）

篮子净值采用 **前一日市值加权复权指数**（`T-1` 已生效成分 × `T-1` 市值权重；市值覆盖率 `< 70%` 当日置空，绝不静默切换等权）。设滚动窗口内历史有效观测为 $x_{t-W+1}, \dots, x_{t-1}$（不含当日自比较，无前视），当日值 $x_t$ 的百分位定义为：

$$P_t = \frac{\#\{i < t : x_i < x_t\} + 0.5 \cdot \#\{i < t : x_i = x_t\}}{N_{\text{valid}}} \times 100 \in [0, 100]$$

| 维度（权重） | 子指标（总分权重） | 原始信号定义 | 回看窗口 | 方向与门控 |
|---|---|---|---|---|
| **收益率（1/3）** | 年线偏离分 `S_mom`（1/6） | `Index_t / MA200(Index)_t - 1` | 500 交易日 | 越高越拥挤：`P / 10` |
| **收益率（1/3）** | 门控波动分 `S_vol`（1/6） | `Std_20d(r_basket - r_SPY) * sqrt(252)` | 500 交易日 | `(P / 10) * dd_gate(DD60)`：`DD60 <= 5%` 取 `1`，`5%–20%` 线性衰减，`>= 20%` 取 `0` |
| **交易量（1/3）** | 成交占比分 `S_dvs`（1/6） | `MA5(篮子成分股美元成交额 / 本库美股普通股总成交额)` | 500 交易日 | 越高越拥挤：`P / 10`（不含 ETF 自身代码，合并双股权副股成交额） |
| **交易量（1/3）** | 换手率分 `S_trn`（1/6） | `MA5(匹配成分股美元成交额 / 匹配成分股总市值)` | 500 交易日 | 越高越拥挤：`P / 10`（故意不乘回撤门控，保留高位放量回调识别能力） |
| **估值（1/3）** | 市销率估值分 `S_val`（1/3） | 聚合市销率倒数 `TTM SP = sum(TTM_Rev_USD) / sum(MCap)` | **500–1000 日有界扩展窗** | 反向昂贵分位：`(100 - P) / 10`（P/S 越贵分越高） |

**合成与后置平滑**：
- 5 个原始子分共同有效时，同步递推因果 `EMA3`（$\alpha = 0.5$）：$S_k^{(t)} = 0.5 s_{k,t} + 0.5 S_k^{(t-1)}$。
- 三维度均分：$D_{\text{ret}} = \frac{S_{\text{mom}} + S_{\text{vol}}}{2}$，$D_{\text{vol}} = \frac{S_{\text{dvs}} + S_{\text{trn}}}{2}$，$D_{\text{val}} = S_{\text{val}}$。
- 最终拥挤度：$\text{Crowding}_t = \frac{D_{\text{ret}} + D_{\text{vol}} + D_{\text{val}}}{3} \equiv \text{EMA3}(\text{Crowding}_{\text{raw}, t})$。

## 4. 数据卫生防线（已内置于 `engine.py`）

1. **拆股与价量配对**：复权收益率统一走 `PriceBook`；当日美元成交额直接用同日未复权 `close * volume`（禁止复权价乘原始成交量）；对 `PriceBook` 标记的拆股存疑日（`split_suspect` / `unresolved`）同步屏蔽收益率与成交额。
2. **市值瞬时脏点清洗**：对 `historical_market_cap` 计算隐含股数 `market_cap / adj_close`，因果剔除相对近 60 期中位数跳变超 `3.2x` 且未持续满 25 根 K 线的瞬时上游脏点（如 `BRK-B` 2026-11 连续 8 天千倍缩水、`EXE`、`L`、`UMC`），再用同发行人副股回填与 15 日复权价格比外推桥接。
3. **财报披露时点与版本回放**：
   - 披露生效日取 `min(accepted_date, filing_date) + 1 天`（要求晚于财季末至少 6 天过滤占位符）；缺失时按 `±21` 天容差匹配 `fmp_earnings.announce_date + 1 天`；早期外国发行人（如 2024 年前 `ASML`）两者皆缺时采用保守 `+65` 自然日法定滞后。
   - `2026-08-22` 起叠加 `fundamental_vintage` 按 `observed_at` 逐版本回放，避免事后财报重述改写历史得分。
   - 当新披露四季营收连续性断裂或 `TTM_Rev <= 0`（如 `HUT`）时写入显式撤销事件，立即停止沿用旧正值。
4. **市场分母去重**：剔除 `security_master` 中 `is_etf=1`、`is_fund=1`、`reason='non_common_instrument'`、港股后缀与指数代码，并去重同日并存的改名/临时代码（`BK/BNY`、`SKHYV/SKHY`）。

## 6. 已知边界与后续扩展点

1. **代理回放边界**：`IGV` 与 `XLF` 在 `2026-07-13` 前库内无历史季报持仓，采用首期周快照名单回放，历史前瞻统计带有成分留存偏差，看板已显式标注分界。
2. **财报版本起点**：`fundamental_vintage` 自 `2026-08-22` 起采集，更早日期使用 `income_quarterly` 当前表数值。
3. **使用定位**：拥挤度是 **情绪与赔率温度计**（辅助判断追高风险、止盈节奏或放量回调换手 vs 缩量冷清低位），分档 60 日重叠窗口仅为描述性统计，不作为单因子机械做空或抄底触发器。
4. **对接新主题池（`P-OWE-10`）**：待 `股票主题分类` 新架构落地后，只需在 `engine.py:load_baskets_pit()` 新增对应主题成员快照源，即可零改动复用整套打分与看板管线。
